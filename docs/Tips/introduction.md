# API Errors

This section covers common API errors you may encounter when integrating with Ideabiz APIs, along with guidance on how to resolve them.

For a detailed list of error codes and their meanings, please refer to the [Error Codes](error_codes.md) page.

## Common Error Categories

- **Authentication Errors** — Issues with tokens, credentials, or expired sessions.
- **Validation Errors** — Malformed requests, missing parameters, or invalid values.
- **Server Errors** — Platform-side issues or rate-limiting.

## Troubleshooting Steps

1. Verify your access token is valid and not expired.
2. Ensure the request headers include `Content-Type`, `Authorization`, and `Accept`.
3. Confirm the MSISDN format matches the required pattern (e.g., `tel:+94xxxxxxxxx`).
4. Check response codes and error messages for specific details.
5. Contact the Developer Support Team at `support@ideabiz.lk` if the issue persists.
